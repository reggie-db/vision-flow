Vision Flow

Using AI on Databricks to generate the schema, dashboard, and extraction for a new document type, then load each photo as a typed row.

Auditing daily lottery receipts

A customer submits lottery sales to the state every day. Staff checked each receipt by hand before the submission, and manual entry introduced errors.

The request: audit every receipt before the daily submission and reduce human error.

Other documents with the same need

The same customer asked whether this approach could also check ID cards and confirm that signed documents are complete.

Two uses of AI in this demo

Read the image

A vision model turns each photo into a structured record with a confidence score per field.

{
  "jurisdiction": { "value": "TX",
                    "confidence": 0.99 },
  "purchase_date": { "value": "2026-11-14",
                     "confidence": 0.95 },
  "total_paid": { "value": 10.00,
                  "confidence": 0.98 }
}

Generate the structure

From a one-sentence description, AI generates the schema to collect, a dashboard page for that schema, and the extraction instructions the pipeline runs.

  • Schemafields, types, required checks
  • Dashboarda page built from that schema
  • Extractioninstructions the pipeline runs

Most of the demo covers the second use.

From a prompt to ingested data

One continuous Lakeflow pipeline handles every schema. Adding a document type adds a schema; the pipeline stays the same.
